# NotesMate 编辑器规范

> 本文件是编辑器行为的唯一权威定义。实现（`NotesMate/Editor/` 各模块）必须与本规范保持一致；规范变更先改本文件，再改实现。
>
> 保存规则：使用备忘录支持的 HTML；图片先经附件 API 交付，再以本地文件 URL 在正文原位混排；`name` 不传，由首行自动派生。

## 2. 支持的 Markdown 标志集（封闭集合，此外一律不支持）

### 块级格式
| 标志 | 格式 | 备忘录映射 |
|---|---|---|
| `# ` `## ` `### ` | 标题 1/2/3 | `<h1>`(24px粗体) / `<h2>`(18px粗体) / 14px粗体段落 |
| `- ` / `* ` | 无序列表（≤8 层嵌套） | `<ul><li>` |
| `1. `（1~2 位数字 + `.`） | 有序列表（≤8 层嵌套） | `<ol><li>`，编号每级独立从 1 开始 |
| ` ``` ` + 空格 | 代码块 | 逐行 Courier `<div>`（连续段合并 `<pre>`） |
| 选取/粘贴/拖入图片 | 图片附件独占行，与正文按顺序排列 | 保留原图文出现顺序（含重复引用） |

### 行内格式
| 标志 | 格式 | 备忘录映射 |
|---|---|---|
| `**文本**` / `__文本__` | 粗体 | `<b>` |
| `*文本*` / `_文本_` | 斜体 | `<i>`（中文在备忘录不可靠，系统限制） |
| `~~文本~~` | 删除线 | `<strike>` |
| `` `文本` `` | 行内代码 | `<tt>`（Courier 12px） |
| 下划线 | 无文本标志，仅工具栏/快捷键 | `<u>` |

## 3. 激活方式（每种标志的完整定义）

### 3.1 文本触发（Markdown 自动转换）

**块级触发**（输入空格时判定）：
- 条件：光标在段落行首（段落内光标前只有标记字符本身）；不在代码块内；不在 IME 组合中（见 §7）；段落不是列表项（列表项内不触发标题/代码块，避免歧义）。
- `#`/`##`/`###` + 空格 → 对应标题档，删除标记，光标留在行首（标题属性）。
- `-`/`*` + 空格 → 无序列表项；`N.`（N 为 1~99）+ 空格 → 有序列表项（起始编号忽略，显示从 1 开始）；``` ` ```×3 + 空格 → 代码块。
- 触发后光标所在行即为目标格式，光标 x = 正文起点（列表项为缩进后起点，永远不进排水区）。

**行内配对触发**（输入闭合符时判定）：
- 向前回溯最近的同类型开口符；命中条件：开口符前是行首/空白/标点，开口符与闭合符之间首尾非空白、内部不含同标记符；单字符标记（`*`）不匹配双字符标记（`**`）的半边。
- 命中后：删除两个标记符，区间应用格式，**光标落在内容之后，清空显式行内格式和粘贴字体覆盖，保留当前段落的基础样式**（行内格式永不向后泄漏）。
- 未命中：标记符按普通字符保留。

### 3.2 快捷键
| 键 | 作用域 | 行为 |
|---|---|---|
| ⌘B / ⌘I / ⌘U / ⇧⌘X | 选区或输入属性 | 粗体 / 斜体 / 下划线 / 删除线 |
| ⌘↩（含小键盘 Enter） | 全局 | 保存到备忘录 |
| ⌘Z / ⇧⌘Z | 全局 | 撤销 / 重做（§9 分组规则） |
| ⌘A | 编辑器 | 逐级扩大选区：普通段落 → 全文；连续代码行组成的整个代码块 → 全文；当前列表项（不含下级）→ 所属顶层项及后代 → 全文。已在顶层列表项时直接从当前项扩大到全文；没有内容的选区层级直接跳过，全文为空时保持空选区；最多三次。手动改选或编辑后从新位置重新开始 |
| Tab / Shift+Tab | 列表项 | 层级 ±1（§4 矩阵） |
| Tab / Shift+Tab | 代码块 | 整行增加/减少一级缩进 |
| Tab / Shift+Tab | 普通文本（含标题） | Tab 在光标处插入制表符；Shift+Tab 无操作 |

### 3.3 工具栏
- 「#」段落样式菜单：一级标题 / 正文 / 代码块。文本标志仍支持 `## ` 和 `### `。
- 「Aa」行内菜单：粗体 / 斜体 / 下划线 / 删除线（**不含行内代码**，行内代码仅 `` ` `` 触发）。
- • 与 1. 列表按钮：切换光标段落（或选区段落）的列表格式。
- 发送按钮（含 ⌘↩）。

## 4. 键盘交互矩阵（Enter / Tab / Backspace）

### Enter
| 当前段落 | 行为 |
|---|---|
| 正文 | 新正文段落 |
| 标题（非空） | 新**正文**段落（标题不延续） |
| 列表项（非空） | 新建**同层级**列表项（编号续排） |
| 列表项（空） | 层级 >1 → **提升一层**（不插换行）；层级 =1 → 退出列表为正文段落 |
| 代码块内（行非空） | 块内新行（仍为代码块） |
| 代码块内（空行） | 继续插入代码空行，不退出代码块 |

### 下方向键（↓）
- 代码块内按 Enter 始终换行，允许任意数量的连续空行。
- 在代码块最后一个显示行按 ↓，移入下方已有段落；若代码块位于文档末尾，则追加一个正文空段落并将光标移入，可撤销/重做。
- 自动折行的中间显示行仍正常向下移动；Shift+↓ 仍选择文字，输入法候选期间交由输入法处理。方向键不删除已有代码空行。

### Tab / Shift+Tab
- 列表 Tab：层级 +1（上限 8），编号按新层级重排。
- 列表 Shift+Tab：层级 >1 → −1；层级 =1 → 退出列表。
- 代码块：Tab 在整行行首插入一个制表符；Shift+Tab 删除行首一个制表符（粘贴的空格缩进每次最多删除四个空格）；无缩进时不操作。光标随原文本移动，多行选区覆盖的代码行一起处理，换行后的续行缩进不在本次调整范围。
- 普通文本（含标题）：Tab 在光标处插入一个制表符，有选区时替换选区；Shift+Tab 无操作，不切换焦点。
- 混合选区包含列表或代码行时，仅增减其中列表/代码行的整行缩进，普通行保持原样。
- 行为对「有文字项」与「空项」完全一致（单一实现路径，不再分 pending/storage 两套）。

### Backspace（光标在段落首字符前）
| 当前段落 | 行为 |
|---|---|
| 标题 / 代码块首行 | 降级为正文（不删字符），再按才正常退格 |
| 代码块内部后续行（含空行） | 一次删除与上一代码行之间的换行，光标立即移到合并处，保持代码格式；不得将中间空行降为正文或拆开代码块 |
| 列表项 | 层级 >1 → 提升一层；层级 =1 → 退出列表（不删字符） |
| 正文 | 系统默认（合并上一段落） |

### Delete：系统默认，不做特殊处理。

## 5. 光标与选区规则

1. **光标永不进入排水区**：任何路径（转换、点击、方向键、Tab）光标 x ≥ 当前段落 headIndent。鼠标点击落在排水区时，光标吸附到该段落首字符前（修复「光标出现在项目符左侧」）。
2. 转换触发后光标位置按 §3.1 定义；行内格式按钮/快捷键作用于空选区时只改输入意图；块级格式按钮作用于当前段落节点，包括空段落。
3. 选区跨段落应用块级格式时，作用于选区覆盖的**全部段落**；行内格式作用于选区字符区间。
4. 空列表项的列表格式记录在文档模型中（§11），不依赖 typingAttributes（已实测其 setter 会剥掉 textLists）。

## 6. 排版布局规范（数值定稿）

窗口标题颜色为 #202020，输入框文字（含列表标记）为 #323232；连续代码块使用 #EAEAEA 背景、4pt 圆角，左右内边距 4pt、上下内边距 4pt，与上下相邻正文各留 2pt 外部间距（连续代码段共用一个背景）。背景高度由代码文字行及内边距决定，不包含段后外间距；按 ↓ 在块外新建正文空行时，原代码块背景高度保持不变。

以下字号用于输入框显示；备忘录导出字号保持 §2 的映射，二者独立。

| 项 | 值 |
|---|---|
| 正文 | 系统字体 14pt，段内行距 5pt；非空正文段后 6pt，标题段后 10pt，连续列表项段后 0pt、列表组末尾 6pt；空段落不额外添加段后距，正文与代码交界沿用代码块自身边距；光标颜色 #FCB826，宽度在原生基础上增加 1pt，文字光标及选区高度按字体自然行高计算，不含行距或段间距；混合字号取当前视觉行最大字体，末行与空行遵循同一规则，图片行按图片高度计算，垂直中心按文字基线与字体度量或图片区域对齐，不以段后留白作为中心 |
| 标题 | H1 22pt 粗体 / H2 18pt 粗体 / H3 15pt 粗体；标题段后回车回正文 |
| 行内代码 / 代码块 | Courier 13pt |
| 列表缩进 | 每级 22px（headIndent = 22×层级），最多 8 级 |
| 列表标记 | L1 `●` / L2 `○` / L3 `◆` / L4 `◇` / L5 `■` / L6 `□` / L7 `▲` / L8 `△`；有序列表各级均为十进制 `N.`，每级独立从 1 计数 |
| 标记绘制 | 无序形状用 8pt、有序数字用 14pt；右对齐于排水区右缘内侧 4px，基线与首行文字基线对齐 |
| 图片 | 缩略高度 ≤72px，保持宽高比，以 attachment 排版；直接插图及图片行输入文字时自动分行 |
| 选区背景 | 垂直中心与光标共用文字/图片对齐规则，多行按各视觉行分别绘制；保留系统选区颜色、横向范围及命中行为，不改变其他文字背景或输入法标记 |
| 占位文字 | 中文「现在的想法是…」，英文 “What’s on your mind?”；14pt，位置与正文一致 |
| 浮窗 | 跟随系统深浅外观；14pt 圆角、细描边与系统阴影；标题栏 40pt、底栏 48pt；可边缘拖拽调大小 |
| 编辑区留白 | 正文左起点 16pt、顶部 20pt，长列表编号保留自适应排水区 |
| 主界面语言 | 跟随系统／App 首选语言，中英文；目录名称与用户内容保持原文 |
| 主题实现 | `EditorAppearance` 统一定义 SwiftUI 与 AppKit 动态色；标题复用 AppIcon，选中态使用黄色体系。详见 `docs/design/implementation.md` |

## 7. 输入法（IME）处理规则

1. **组合中（hasMarkedText）不做任何自动转换**：块级/行内触发只在文本 commit（`insertText`）后评估；`insertText(_:replacementRange:)` 带 markedRange 时跳过触发逻辑。
2. 组合中允许主动格式操作：底部段落、字体、列表按钮保持可用，⌘B/⌘I/⌘U/⇧⌘X 也可用。执行时先结束组合并保留当前显示文本（不自动选择尚未显示的候选词），同步模型并关闭候选窗，再按现有选区规则应用格式；空选区的行内格式作用于后续输入。组合输入与格式操作分别支持撤销，不恢复候选窗。Tab/Shift+Tab/Enter 和其它快捷键仍交给 IME/系统默认，不触发自定义列表或发送操作。
3. 中文斜体：编辑器内用 obliqueness 合成倾斜（显示正常）；导出 `<i>`（备忘录端中文斜体无效属系统限制，文档注明，不做额外处理）。
4. 候选窗定位依赖系统 NSTextView 机制，行距/缩进改动后需真机验证候选窗不错位。

## 8. 粘贴规则

1. 富文本粘贴：保留粗体/斜体/下划线/删除线/列表段落结构；等宽源保留为代码字体（Courier 14）；**标题按「粗体 + 字号」映射到标题档位并赋予正确的段落 kind**（粗体 ≥21px → 标题 1、粗体 ≥17px → 标题 2），其余字号一律归一正文。**标题首段按落点分三分支**：①空正文段落——映射为标题段落；②非空落点（正文或列表项的行首/中间/行尾）——**降级为加粗内联文本**内联插入光标处，目标段落格式不变（正文仍是正文、列表项仍是列表项），不切割段落；③空列表行——删除列表格式，标题占据该行。多行片段的**后续段落保持自身 kind**（标题仍是标题、独立成段；片段末段是标题且目标行有后缀时，后缀独立成段）。粘贴只插入字符内容：非标题片段在目标段落为空且带非正文块级格式（空列表项/空标题/空代码行）时首段继承目标格式；多行粘贴进列表项时，后续行中的普通段落成为同级列表项（对齐系统备忘录），自带列表段落保留自身层级（可嵌套），标题段落除外。**列表段落行首的标记符文本**（Chromium 等来源把 `•`/`1.` 写进条目文本，如 `\t•\t`）**一律剥离**，避免与编辑器自绘标记重复；剥空则为空列表项（源片段的空条目是真实内容，保留）。**片段尾部的段落结束符不是内容**：尾部空正文段落一律裁剪，粘贴单段标题不新增空行，多行粘贴的内部空行保留。
2. 图片：剪贴板含图像数据时取第一个可解码表示（png 优先于 tiff），一次粘贴一张；Finder 图像文件 URL 每个文件一张。工具栏支持选择本地图片，可多选。直接插入图片时，每张图片独占一行：插入位置前有同行内容则先换行，选区后仍有同行正文则另起一行保留；已有段落边界不额外添加空行。图片行输入或粘贴文字时，同样与选区之外保留的图片自动分行，中文候选首次出现时即分行；选中图片后输入文字可直接替换图片。自动分行与本次插入组成一次可撤销操作。底层仍使用 attachment 表示图片。
3. 纯文本粘贴：原样插入，不做触发评估（粘贴的 `- ` 不触发列表转换）。

## 9. Undo/Redo 规则

1. 一次自动转换（标记删除 + 格式应用 + 光标移动）为**一个** undo 组。
2. 一次工具栏/快捷键/Tab 操作为一个 undo 组。
3. 连续普通键入按系统默认分组。
4. 撤销后文档模型、光标、列表标记显示三者同步还原。

## 10. 明确不支持的特性（写入文档，不实现、不提示）

- 块引用 `>`（备忘录 HTML 通道不支持，输入保持原文本）
- 链接 `[文字](url)`（保持原文本，不生成链接对象——备忘录丢 href）
- 任务清单 `- [ ]`、表格编辑、水平线 `---`、高亮、上标/下标
- 四级及以上标题、有序列表起始编号、文本对齐
- Markdown 源码模式/标记符回看（本设计为即时转换，标记即转即消）
- 不通过前台粘贴或文件导入保存；图文混排走后台 AppleScript。

## 11. 文档模型与边界裁定

以下规则落实已接受的 EditorDesign 方案，作为实现与验收的共同依据。

1. 文档始终至少有一个段落；正文、标题、列表项和代码行互斥。空段落保有 ID、类型和层级；列表符号不写入正文。输入属性仅是显示缓存。
2. 段落和选区使用 UTF-16 范围映射；文末零长度段落合法。非空选区按半开区间覆盖段落，不包含仅触及起点的下一段。
3. 行内配对限当前段落，最近同类型候选失败即保留原文；三连及以上标记整体不识别，不跨附件、已有行内代码或代码块转换。逐键转换不回溯重解释未来输入。编号标记为 `[1-9][0-9]?`，不接受前导零。
4. 空标题 Enter 原地转正文；空代码行 Enter 保留当前空行并新建正文。“空”是零内容，空格及附件均算非空。
5. 编号限定于同父项、同种类的连续列表组。父项、列表种类或正文中断后重启。Tab 只修改选区覆盖的列表项，不隐式修改未选中的子项。
6. 首项或层级跳跃产生的无父项列表，在编辑器保留原始 22/44/66 缩进；导出压缩缺失祖先层级，不生成虚构空条目。这是备忘录导出的层级降级限制。
7. 混合选区的行内格式：全部已开启则统一关闭，否则统一开启；列表按钮同理。自动转换一次撤销恢复完整字面标记，下一次撤销处理此前键入；历史回放不触发转换。
8. 数值按相同数值的 AppKit 逻辑 point 实现；仅初始空正文显示占位文字。三位以上编号保持右对齐，可伸入左侧预留绘制空间，不缩小字号或改变正文缩进。
9. 富文本粘贴的标题按字号映射到标题档位（kind=heading，独立成段），其余字号归一正文；导出在既定白名单内保留结构、marks、标题档位和等宽字体。
10. 逐字输入 `- [ ]` 时，`- ` 已转换为普通列表，后续 `[ ]` 保留文字，不产生任务语义；纯文本粘贴整串不转换。
11. 只有空格式而不能发送的文档仍需保存草稿。保存成功清空文档和历史，保存失败保持原稿。Undo/Redo 后 revision 单调递增。
12. 代码区域禁用 Markdown 自动触发；工具栏显式行内格式仍可使用。块格式切换后继承目标块基础样式，不残留之前粘贴的字号覆盖。

## 13. 图文后台保存

按图片每次出现的位置生成独立临时 PNG 和 HTML 槽位。先创建笔记，再通过附件 API 交付全部图片，最后重写含本地文件 URL 的完整 HTML。完成后校验附件数量及逐张导出数据与源图一致，才清理临时文件并清空草稿。校验失败保留草稿并尝试移除本次未完成笔记；若移除失败或创建结果不明确，保留临时图片并告知检查备忘录，避免盲目重试造成重复。纯文字仍直接后台创建，不触碰剪贴板或窗口焦点。
